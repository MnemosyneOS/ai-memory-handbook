## 1. 白皮书架构与写作背景

2025 年，我们发布了 Mnemosyne OS 的第一版，围绕「AI Agent 如何长期记住用户」这件事，从本地优先的存储引擎、零第三方依赖的部署形态、可审计的记忆账本到无损压缩，做了一次体系化的尝试。但随着记忆从 Agent 的附属功能变成一等原语，我们发现市场的关注度已经从「能不能记住」转向以下三大新挑战：

*   **工程化挑战**：从「能召回」到「可信召回」，记忆要能承担关键任务。

*   **规模化挑战**：稳定、安全、性能、成本，从单机试验到记忆基础设施，记忆要能被大规模部署。

*   **治理化挑战**：从「记住」到「可解释、可推翻、可彻底遗忘」，记忆要能进入核心业务流程与合规体系。

早期的技术文档，显然难以应对这些新的诉求。

因此，我们重新梳理了白皮书的架构，希望通过更与时俱进的内容、更高的实践篇幅占比，以及更社区化的协作，为企业选型和内部立项提供参考，并通过开源的方式长期维护该白皮书，持续呈现 AI 记忆架构的前沿思考和落地实践。

## 2. 目标读者与收获

本白皮书主要面向企业级 AI 记忆系统的构建与落地场景。它既适合关注记忆系统开发的工程人员，也适合用于企业内部的技术选型、架构评审、项目立项和跨团队共识建设。

| 读者 | 建议关注 | 你将获得 |
| --- | --- | --- |
| Agent / AI 应用开发者 | 构建篇、运行篇、调优篇 | 掌握单遍写入、冲突消解、多信号检索、渐进式披露、MCP 接入等核心工程方法。 |
| 架构师与平台工程师 | 架构篇、运行篇、治理篇 | 建立从存储引擎到治理底座的完整架构视图，形成可扩展的记忆基础设施设计。 |
| 技术负责人和研发管理者 | 架构篇、治理篇、实践篇 | 判断记忆系统的成熟度、选型边界、投入边界与生产风险，支撑选型、立项和组织协同。 |
| 产品与业务负责人 | 技术观察、架构篇、实践篇 | 理解不同场景对记忆的期待与恐惧，以及从「记住」走向「被信任」的产品条件。 |
| 安全、质量与运维人员 | 运行篇、治理篇、调优篇 | 建立可观测、哈希链审计、级联删除、上线验证、持续评估和故障归因机制。 |
| 研究者与生态贡献者 | 全书与实践篇 | 了解企业一线问题、工程抽象和开放议题，并参与共同完善行业知识体系。 |

完整阅读后，你将能够：

- 判断一个场景的记忆需求属于哪一级成熟度，据此决定投入边界；
- 区分「尽力而为」与「强保证」两类机制，不被过度承诺误导；
- 设计可被脚本验证的审计、删除与隔离方案，而不是依赖流程与人工；
- 读懂基准分数背后的方法学差异，知道哪些数字可以比较、哪些不能；
- 为记忆系统建立从 Trace 到 Badcase 再到受控发布的改进闭环。

## 4. 下一步规划

白皮书将以开放项目的方式持续维护，而不是在首次发布后封存。接下来的重点包括：

- **补齐基准的完整复算**：把当前仅有骨架的基准仓库推进到「任意第三方可一条命令复算出 headline 分数」的状态，并公开每次运行的机器可读记录。
- **扩展企业实践案例**：增加更多来自研发、运营、客服、数据、安全、财务和行业场景的一线案例，补充成功路径、架构取舍与真实失败模式。
- **扩展中文与非英语场景**：现有主流基准以英语为中心，中文的专有名词、时间表达、近义表达在纯嵌入召回下失准明显，需要独立的对照实验与数据集。
- **深化删除可验证性**：尝试给出一种可跨系统交换的删除审计格式，使「已彻底清除」从口头承诺变为可验证事实。
- **补充跨 Agent 共享的权限模型**：把「共享读」与「共享写」分开设计，先解决读侧的一致性，再讨论写侧的仲裁。
- **跟进技术演进**：持续吸收记忆分层、上下文工程、Runtime 与多 Agent 治理的新进展，并及时修正已经不再适用的判断。
- **建设社区协作机制**：逐步完善内容规范、案例模板、术语表、校对流程和版本发布方式，降低高质量贡献的门槛。

## 5. 关于本书的数据与事实

本书对事实的处理遵循三条规则，请读者据此判断可信度。

**第一，所有数字都标注口径与时间。** 基准分数标注数据集版本、judge 类型与是否完整运行；价格标注币种与生效时间；论文标注 arXiv 编号。没有口径的数字不出现。

**第二，无法核验的论断一律删除，而不是弱化表述。** 本书不写「据传」「业内普遍认为」这类无法追溯来源的判断。少数必须提及但证据不足的内容，会明确写出「截至 2026 年 10 月的公开文档中未见说明」。

**第三，对自家实现与对竞品采用同一套审慎标准。** 书中对 Mnemosyne OS 的描述同样标注边界与代价，包括其基准分数尚未由仓库内一次完整运行独立复算这一事实（见第 16 章）。对竞品的描述只写其边界，不写其弱点。

读者若发现任何数字与本手册所述口径不符，应当以原始来源为准。附录 B 给出全部可复现资源的入口。
